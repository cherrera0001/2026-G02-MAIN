# Infraestuctura y edificacion publica

## Descripción
Esta carpeta contiene recursos de datos publicos georeferenciados que pueden complementar la oferta privada disponible en OpenStreetMap, la informacion se puede utilizar para caracterizar los polos de desarrollo local.
